# hdnews 모바일 홈·이슈 타임라인 개편

## 🎯 목표
현재 hdnews(https://hdmzp.github.io/hdnews/)는 유통 업계와 홈쇼핑 12개사의 뉴스를 30분마다 자동 수집해 보여주지만, 화면이 "탭 + 긴 기사 목록" 구조라 모바일에서 오늘 무슨 일이 있었는지 한눈에 파악하기 어렵고, 같은 사건을 다룬 전재 기사가 반복 노출됩니다. 캐치테이블처럼 아이콘 바로가기와 회사 선택이 있는 홈 화면, 뉴닉처럼 같은 사건의 기사를 하나의 "이슈"로 묶어 시간순으로 정리하고 팔로우할 수 있는 이슈 타임라인을 도입해, 출근길 3분 안에 핵심 이슈를 파악하고 관심 이슈의 후속 보도를 놓치지 않게 합니다. 서버 비용 없이 지금처럼 자동 수집·무료 호스팅 구조는 그대로 유지합니다.

## 👥 타겟 사용자
- 홈쇼핑사 홍보·대외협력 담당자: 자사·경쟁사 보도와 리스크 기사를 매일 아침 모바일로 빠르게 확인
- 유통업계 전략·기획 담당자: 업계 이슈의 흐름을 시간순으로 파악하고 후속 보도를 추적
- 경영진·팀 리더: 핵심 이슈 TOP과 회사별 요약만 짧게 훑어보고 필요한 기사만 열람
- hdnews 운영자: 설정 파일만 고쳐 바로가기 항목과 이슈 묶음 기준을 조정

## ✨ 핵심 기능
1. 홈 화면 바로가기 그리드: 급상승 키워드, 핫이슈 TOP10, 리스크, 재승인·인허가, 송출수수료, 방송사고·심의, 뒷광고·PPL, 국회·국감, 소비자 피해, e커머스, 정책 등 주제 아이콘을 격자로 배치하고, 마지막으로 본 뒤 새 기사가 있으면 N 배지 표시
2. "어느 회사를 보시나요?" 회사 선택: 12개 홈쇼핑사를 회사 색상의 원형 카드로 가로 나열하고, 오늘 기사가 많으면 '인기', 리스크 기사가 있으면 '주의' 배지를 붙이며, 누르면 해당 회사 대시보드로 이동. '내 회사' 버튼으로 자주 보는 회사를 직접 지정하면(기본값 없음) 홈 상단에 그 회사의 오늘 요약 카드가 표시됨
3. 이슈 타임라인 목록: 같은 사건을 다룬 기사(전재·후속)를 하나의 이슈로 묶어 "N개의 기사를 압축했어요 · n분 전" 형식으로 최신순 나열, NEW 배지, 전체/팔로우 필터
4. 이슈 상세: 이슈에 속한 기사를 시간순으로 정리(날짜 구분선, 언론사·시각, 리스크 색 테두리)하고 대표 요약 1~2줄과 관련 회사 태그를 표시, 기사별 ★ 스크랩 가능
5. 이슈 팔로우(종 아이콘): 관심 이슈를 팔로우하면 팔로우 필터에서 모아보고, 새 기사가 붙으면 NEW 배지와 홈 알림 점으로 알려줌(로그인 없이 이 기기에 저장)
6. 발견 탭: 카테고리 칩(전체/유통/홈쇼핑/정책/e커머스/리스크)으로 "이슈 타임라인 — 시간 순으로 핵심만 정리했어요" 칩 묶음, 회사 대시보드 카드, 급상승 키워드를 둘러보기(더 보기 → 전체 목록)
7. 모바일 하단 내비게이션: 홈 / 발견 / 이슈 / 스크랩 / 회사 5개 탭과 상단 검색·최근 본 기사·알림 아이콘을 두고, PC에서는 기존 좌측 메뉴를 유지

## 🔄 유저 플로우
1. 아침에 모바일로 hdnews를 열면 홈 화면에 검색바, 알림 점, 주제 바로가기 그리드(N 배지), 회사 원형 카드가 보인다
2. 바로가기 '리스크'를 눌러 오늘의 리스크 기사 목록을 확인하고 홈으로 돌아오면 N 배지가 사라진다
3. 하단 '이슈' 탭에서 "N개의 기사를 압축했어요" 이슈 목록을 훑고, NEW 배지가 붙은 이슈를 연다
4. 이슈 상세에서 시간순으로 정리된 기사 흐름을 읽고 필요한 기사를 ★ 스크랩한다
5. 종 아이콘을 눌러 이 이슈를 팔로우한다
6. 다음 날 홈 알림 점이 켜지고, 이슈 탭의 '팔로우' 필터에서 새 기사가 추가된 이슈를 바로 확인한다
7. '발견' 탭에서 카테고리 칩 '홈쇼핑'을 눌러 홈쇼핑 이슈 칩과 회사 카드를 둘러보고, 회사 카드로 회사 대시보드에 들어간다

## 📏 성공 기준
- 모바일(390px 폭)에서 홈 첫 화면에 검색바, 바로가기 그리드(최소 10개), 회사 선택 영역이 가로 스크롤 없이 표시된다
- 바로가기 N 배지는 사용자가 그 주제를 마지막으로 연 이후 새 기사가 있을 때만 표시되고, 열면 사라진다
- 최근 72시간 기사 중 보도 3건 이상이 묶인 사건은 이슈로 생성되고, 이슈 목록 각 항목에 기사 수와 마지막 기사 시각이 표시된다
- 이슈 상세는 기사를 최신순으로 보여주고 날짜가 바뀌는 지점마다 구분선이 있다
- 이슈 팔로우/해제가 즉시 반영되고 새로고침 후에도 유지되며, 팔로우한 이슈에 새 기사가 붙으면 NEW 배지와 홈 알림 점이 켜진다
- 발견 탭 카테고리 칩을 바꾸면 이슈 칩·회사 카드·급상승 키워드가 해당 카테고리 기준으로 1초 안에 바뀐다
- 기존 기능(유통/홈쇼핑 기사 피드, 회사 대시보드, 스크랩, 검색, 다크/라이트 테마)이 그대로 동작하고, 30분 자동 수집·무료 호스팅 구조가 유지된다
- PC(1024px 이상)에서는 기존 좌측 메뉴가 유지되고 하단 내비게이션은 보이지 않는다
